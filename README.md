# rohandisa.github.io

Static Astro 5 portfolio for Rohan Disa. Built from `SPEC.md` and deployed to GitHub Pages.

## Commands

| Command | Action |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start the local dev server |
| `npm run build` | Build the production site to `./dist/` |
| `npm run preview` | Preview the production build |

## Deploy

The site deploys from `.github/workflows/deploy.yml` on push to `main`. In the GitHub repo, set Settings > Pages > Source to GitHub Actions.
